## 다음 작업과 남은 확인

- 샘플 맵은 기존 4개 테마의 모듈러 에셋을 조합하고, 사용자 제공 예시처럼 쿼터뷰 시점에 어울리도록 제작한다. [확정 방향과 참고 이미지](PROJECT.md#샘플-맵-제작-방향-쿼터뷰)를 먼저 확인한다. 세부 카메라 값·투영 방식은 미정이다.
- [지역 연결 구조](PROJECT.md#샘플-맵-지역-연결-구조)는 중앙 숲과 Snowy Mountain·Swamp·Volcano의 양방향 연결로 확정했다. 바깥 세 지역 사이의 직접 연결은 없으며 다른 지역으로 이동하려면 반드시 숲을 거친다. 상세 방위·통로·규모는 미정이고, 이 기준 기록 작업에서는 씬·카메라를 변경하지 않았다.
- `StatusEffectDatabase` SO 스크립트에 목록 검증과 타입별 조회를 구현했다. API와 위치는 [프로젝트 안내](PROJECT.md#상태-효과-데이터-조회)에 기록했다.
- 다음 연결 작업은 Database 에셋 생성·상태 SO 목록 등록 및 Manager의 `GetSOData()` 구현이다. 이번 요청에서는 스크립트만 작성했으며 에셋·씬·Manager 연결은 변경하지 않았다.
- Snowy Mountain의 URP 셰이더·연기·별·눈 파티클 수정과 관련 컴파일·대표 렌더 검증을 완료했다. Synty Dungeon Map은 기반 POLYGON Dungeon Pack 원본이 없어 원본 재질 복원이 불가능한 상태이며 조사만 수행했다. 범위·근거·미검증 부분은 [작업 계획](plans/2026-11-03-snowy-urp.md)을 따른다.
