# Pomunculus
기업협약 프로젝트 2팀
## 멀티 연동 관련 가이드
IWorldObj
-멀티플레이 연동이 되야하는 모든 오브젝트들은 해당 인터페이스를 구현해야함
-포톤뷰를 대체함
-IdOwner로서 해당 인터페이스의 ID 구현이 포톤뷰의 ViewID 및 저장 시 uid의 역할을 함

IPlayerObj
-Player 전용 인터페이스. 소유자를 가리기 위해 추가한 인터페이스인데 플레이어 옵젝 외에는 해당사항 없으니 사용하지 말것
-IWorldObj 구현을 포함함

IWorldRPC
-포톤뷰를 쓰지 않아 기본적으로 사용 불가한 RPC 패턴을 사용하기 위한 인터페이스
-IWorldObj 구현을 포함함
-구현시 확장 메소드로 SendRPC사용 가능. 해당 개체의 ReceiveRPC 메소드를 호출함

ITMPWorldObj
-월드 저장에 포함되지 않는, 일회성 개체를 의미
-IWorldObj 구현을 포함함
-이걸로 오브젝트를 구현하면 월드 저장 및 불러오기에서 제외됨
-스냅샷에는 제외 안되니 월드 동기화에는 지장없음
-포션 투사체, 드랍 아이템(기획봐서) 등 한시적이고 저장 시 미포함할 오브젝트에 구현
